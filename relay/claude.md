## 常见问题

**Claude 中转站和 Anthropic 官方 API 有什么区别？**

调用的是同样的 Claude 模型。区别在于不用海外信用卡和海外手机号，支付宝、微信就能充值，按量计费；同一款 Claude 在不同站的价格能差好几倍。

**Claude 中转站怎么接入？**

多数中转站同时提供 OpenAI 兼容格式和 Anthropic 原生格式：把 base_url 换成中转站地址，key 填中转站后台创建的，model 填站方给的 Claude 模型名即可。

**Claude 中转站能同时用别的模型吗？**

大多数能。同一个 key 换个 model 名，就能调 GPT、Gemini、Kimi、GLM 等其他模型，各家报价见全部中转站那一页。

**怎么挑 Claude 中转站？**

先看你要用的那一款在下表的输入、输出价，再看后面几列：本页 306 家里，支付宝能充 80 家、写明能开发票 50 家。按起充金额挑看「支付宝能充」那一页，公司报销看「能开发票」那一页。
