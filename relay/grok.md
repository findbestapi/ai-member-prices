## 常见问题

**Grok 中转站和 xAI 官方 API 有什么区别？**

调用的是同样的 Grok 模型。区别在于不用海外信用卡和代理，支付宝、微信就能充值，按量计费；同一款 Grok 在不同站的价格能差好几倍。

**Grok 中转站怎么接入？**

中转站一般把 Grok 做成 OpenAI 兼容格式：base_url 换成中转站地址，model 填站方给的 Grok 模型名，key 用中转站后台创建的即可。

**Grok 中转站能同时用别的模型吗？**

大多数能。同一个 key 换个 model 名，就能调 GPT、Claude、Gemini 等其他模型，各家报价见全部中转站那一页。

**怎么挑 Grok 中转站？**

先看你要用的那一款在下表的输入、输出价，再看后面几列：本页 163 家里，支付宝能充 36 家、写明能开发票 32 家。按起充金额挑看「支付宝能充」那一页，公司报销看「能开发票」那一页。
