## 常见问题

**GPT 中转站和 OpenAI 官方 API 有什么区别？**

调用的是同样的 GPT 模型，接口兼容 OpenAI 官方 SDK，只需改 base_url 和 key。区别在于不用海外信用卡，支付宝、微信就能充值，按量计费；同一款 GPT 在不同站的价格能差好几倍。

**OpenAI 中转站怎么接入？**

用 OpenAI 官方 Python / Node SDK 时，把 base_url 设成中转站地址（一般以 /v1 结尾），api_key 填中转站后台创建的 key，其余代码不用改。

**GPT 中转站能同时用别的模型吗？**

大多数能。同一个 key 换个 model 名，就能调 Claude、Gemini、Kimi、GLM 等其他模型，各家报价见全部中转站那一页。

**怎么挑 GPT 中转站？**

先看你要用的那一款 GPT 在下表的输入、输出价，再看支付方式和起充金额；先小额充值试过速度和稳定性再加钱。
