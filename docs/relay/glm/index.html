常见问题

GLM 中转站和智谱官方 API 有什么区别？
智谱官方可以直接充值；用中转站的好处是一个 key 同时调用 GLM、GPT、Claude 等多家模型，账单也在一处。价格各站不同，下表是今天的报价。
GLM 中转站怎么接入？
中转站一般把 GLM 做成 OpenAI 兼容格式：base_url 换成中转站地址，model 填站方给的 GLM 模型名，key 用中转站后台创建的即可。
