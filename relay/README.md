## 常见问题

**API 中转站是什么？**

中转站把 OpenAI、Anthropic、Google 等厂商的官方 API 转一手卖给国内用户：国内网络直连，支付宝、微信就能充值，按 token 用量扣费，一个 key 可以切换 GPT、Claude、Gemini、Kimi、GLM 等多个模型。

**中转站和官方 API 有什么区别？**

调用的是同样的模型，接口大多兼容 OpenAI 格式。区别在买法：不用海外信用卡和代理，按量付费、充值门槛低；但同一个模型在不同站的价格能差好几倍，所以值得先比一比。

**怎么接入中转站？**

在中转站注册、充值后创建一个 API key，把程序里的 base_url 换成中转站给的地址、再填上这个 key 就能用；Cherry Studio、Cursor 等客户端在设置里改同样两项即可。

**用得少，选中转站还是买官方会员？**

用得少、或者要在几家模型之间切换，按量计费的中转站更划算；每天重度用对话，官方会员更省心，会员代充价格在本仓库首页可以查到。

**第一次用中转站要注意什么？**

先按起充金额小额充值，试过速度和稳定性再加钱；余额大多不退，充多少用多少。
